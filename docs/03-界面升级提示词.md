# 第三步：技术约束

1. **零依赖。** 不许引入任何 npm 包、CSS 框架、图标库、动画库、字体服务。
   现有字体通过 Google Fonts 异步加载（Space Grotesk + JetBrains Mono），
   保留这个加载方式（它有防阻塞的写法，不要改坏），并保留完整的系统字体兜底栈。
2. **不碰 JS。** 不改 public/js/ 下任何文件。所有效果靠 CSS 完成；确实需要新元素时在 HTML 里加。
3. **保持单文件。** 样式全部写在 public/styles.css 里，不要拆文件、不要内联 <style> 大段样式。
4. **保持无构建。** 不要引入 Tailwind / PostCSS / Sass / 任何编译步骤。
5. **性能。**
   - 动画只做 `transform` / `opacity` / `filter`，避免动画 `width/height/top/left/margin`（会触发重排）。
   - 长列表（会话历史、接口列表）不要用重阴影或 backdrop-filter 堆叠。
   - 背景动效要能用 `will-change` 之外的纯 CSS 实现，且不能导致持续重绘整个页面。
6. **无障碍。**
   - 保留 `:focus-visible` 可见焦点环（且要比现在更明显）。
   - 保留 `.skip-link`。
   - 正文文字与背景对比度不低于 4.5:1，次要文字不低于 3:1。
   - **所有动效都要在 `@media (prefers-reduced-motion: reduce)` 下降级为「无动画但有最终态」**，
     不能只是把动画删掉导致元素消失或状态不可辨。
7. **兼容。** 目标环境是 Chromium / Edge 桌面版，可以用现代 CSS
   （`:has()`、`color-mix()`、`oklch()`、`@property`、容器查询、`@view-transition` 等），
   但**不要用只在 Safari/Firefox 才有的特性**。用了新特性要保证降级后界面仍然可用。

# 第四步：视觉方向

**主推方向：深空玻璃 · 能量流（Deep Space Glass / Energy Flow）**

整体气质：高级、冷静、有科技感但不廉价。描述细节：

- **底子**：深空蓝黑（比现在的 `#0d1117` 更有色彩倾向，例如带一点冷蓝或靛青）。
  叠一层极细的网格 + 极淡的噪点（用 CSS 渐变或 SVG data-URI 实现，不要引外部图片），
  让大片深色不显得平。
- **层次**：面板用「玻璃拟态」——半透明表面 + 细微边框 + 内高光（`inset box-shadow`）+ 柔和外阴影。
  层次之间靠亮度和描边区分，而不是靠粗重的分割线。圆角统一到一套令牌（建议 10/14/20 三档）。
- **强调色**：用青 → 紫的渐变作为"能量"的表达（例如 `#4dd8e8` → `#8b7cff`），
  只用在：主按钮、当前激活的标签、流水线的推进光带、聚焦环、生成中的进度提示。
  **不要**到处铺渐变——让强调色稀缺才显高级。
- **状态色**：成功=青绿、警告=琥珀、危险=红。沿用现有语义
  （`--green` 只用于"机器状态确认"，`--red` 用于危险/错误）。
- **文字**：主文本近白但不刺眼（如 `#e8ecf2`），次要文本用带透明度的同色系。
  数字一律 `font-variant-numeric: tabular-nums`（现有代码已经这么做了，保留）。
- **纪律**：所有颜色、圆角、阴影、间距、缓动曲线都收敛成 `:root` 里的一套设计令牌，
  不要散落魔法数字。这样以后换主题只改一处。

# 第五步：动效清单（这是本次的重点）

用户最想要的就是「动感」。请逐条落实，并且**每条都要说明触发时机 + 用了什么属性 + reduced-motion 下怎么降级**。
核心理念：**动效用来表达"发生了什么"，不是用来炫技**。节奏要稳，时长多在 120–320ms 之间，
长动效（背景漂移、呼吸）放在 4–12s 的慢周期里。

1. **阶段流水线（.stages / .stage）—— 最强的一个动效，做好它。**
   - 待机态：四个阶段之间用一条细连接线串起来，弱对比。
   - `active` 态：当前阶段的连接线变成一段**流动的光带**（用 `background-position` 或
     `transform: translateX` 驱动一个渐变遮罩），点标有柔和的呼吸光环。
   - `done` 态：光带"灌满"到当前节点，节点做一次短促的确认脉冲，然后稳定为完成色。
   - `skipped` 态：整体降透明 + 一道细斜线划过的"跳过"暗示。
   - `error` 态：节点变红，做一次轻微抖动（**只抖 2 次，幅度要小**）。
   - 整个过程要像"能量从解析流向修订"，而不是四个孤立的点各自闪。

2. **流式生成时的编辑器（#promptOut / .editor-shell）**
   - 生成中：面板边缘有一道**跑马灯式的微光**（沿边框循环移动），表达"正在写入"。
     实现建议：伪元素 + `mask` + `translate`，不要用 box-shadow 动画。
   - 文本光标：编辑器获得焦点时用 `caret-color` 设为强调色；
     生成中可加一个呼吸的 `caret-color` 动画（如果浏览器支持，否则跳过）。
   - 生成结束：一次短暂的"定型"效果——边框微光收敛 + 轻微高亮闪一下（≤300ms）。

3. **面板 / 标签切换（.tab / .panel / .is-active）**
   - 切换时新内容**淡入 + 从下往上浮 6–10px**（200ms 左右，`cubic-bezier` 收尾）。
   - 激活标签下加一个**会滑动的指示条**（用伪元素 + `transform`，不要用 `left`）。
   - 标签文字颜色渐变过渡，不要瞬间跳变。

4. **卡片与列表的错峰入场（stagger）**
   - 接口列表（.pf-item）、会话列表（.session-row）、多模型选项卡（.model-tab）、
     沟通气泡（.bubble）在渲染出来时，**逐条错峰入场**（每条延迟 30–50ms，总时长不超过 500ms）。
   - 用 `@starting-style` + `transition-delay` 或 `animation-delay` 实现；
     注意这些元素是 JS 用 innerHTML 一次性插入的，所以**不要依赖逐个加 class**，
     尽量用 `:nth-child()` 计算公式或纯 CSS 入场。

5. **多模型对比的并发出场（#modelTabs / #modelBody）**
   - 两个模型同时生成时，各自的选项卡要有**独立的进行中状态**（转动的细环或流动的下划线）。
   - 先出结果的先"定型"，后出的后定型——用 `animation-delay` 或让完成态样式自然错开。

6. **交互反馈（全局）**
   - 所有按钮：hover 时轻微上浮 1px + 强调色光晕（120ms）；
     active 时下压 1px + 缩短的阴影（80ms，要"弹"一下）。
   - 焦点态：`:focus-visible` 用强调色描边 + 柔和外发光，比现在更明显。
   - 链接类按钮（.linklike）：hover 时下划线从中间展开。

7. **数字与计量（#meter / #scoreChip / .model-tab-meta / .chat-round）**
   - 数值变化时做一次**轻微跳动**（`transform: scale(1 → 1.06 → 1)`，180ms），
     让"数字在动"这件事被感知到，但不要重排。
   - 自评分数徽标出现时：从 0 **计数到目标值**（用 CSS `@property` + `counter`/`@keyframes` 实现，
     纯 CSS 方案优先；做不到就退化成一次缩放 + 高亮）。
   - 徽标按 `data-band` 有高/中/低三档配色，切换档位时颜色要**渐变过渡**而不是硬切。

8. **服务连接状态（#modeChip[data-state]）**
   - `online`：状态点带一圈缓慢扩散的脉冲（2s 周期）。
   - `busy`：状态点旋转或呼吸。
   - `down`：状态点闪烁（要克制，1.2s 一次，别做成警报灯）。
   - 状态切换时整体做一次 200ms 的交叉淡入。

9. **全屏编辑（.is-fullscreen / .has-fullscreen）**
   - 进入全屏时**用一次平滑的放大过渡**（`transform: scale` + 圆角/阴影同步过渡，280ms），
     而不是瞬间跳变。退出时反向。
   - 注意这个 class 加在 `.sheet-frame` 和 `body` 上，两边的过渡要协调。

10. **背景（body）**
    - 网格做**极缓的漂移**（例如 60s 线性循环平移一个网格周期）——肉眼几乎察觉不到在动，
      但对比静态截图能看出"活的"。
    - 可以在顶部或某个角落加一个**极慢的能量渐变呼吸**（8–12s 周期，透明度变化幅度 < 6%）。
    - 用 `prefers-reduced-motion` 完全关掉。

11. **空状态与占位（#emptyState / .empty-mark / .chat-empty / .placeholder）**
