## 5. 遗留风险

1. **U6 用例的补参是我对"测试本意"的判断**。如果你更希望保持测试原样（那就必须接受 U6 永远红），我可以回退这一处并写明"该断言不可满足"。
2. **DPAPI 依赖 PowerShell**。若被组策略/EDR 拦截，密钥会退化为 base64 伪加密 —— 现在有服务端告警 + 页面顶部可见告警条，但**保护强度确实下降**，属于环境限制而非代码可解。
3. **`/api/*` 的 Host/Origin 白名单按 `127.0.0.1`/`localhost`/`[::1]` 判定**。用机器名（如 `http://my-pc:5178`）访问时会被 403；本地工具有意收窄，如果确实需要按机器名访问，需要把主机名加进白名单。
4. **日志环状缓冲上限 60 条**，超长会话会截断最早的几条（关键信息都在尾部，影响很小）。
5. **`test-front.mjs` 的 DOM 桩是手写最小实现**（`innerHTML`/`appendChild` 是空壳），所以我的日志改造特意选"多行 `textContent`"而不是拼 DOM 节点 —— 真实浏览器里靠 CSS `pre-line` 分行渲染，两边都能验证。若将来有人把日志改成真 DOM 列表，这条用例的断言方式需要同步调整。
6. **回填时 data 目录没动**，所以你机器上那份真实配置（含加密后的 Key）保持原样；若换了 Windows 账户，DPAPI 解不开需要重填 —— 界面会提示"密钥解不开"。
