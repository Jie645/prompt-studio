### 3.2 缺陷详情

#### BUG-01｜S2 / P2 / 安全｜历史条目属性注入

- **复现步骤**
  1. 输入需求：`带引号的需求 " onmouseover="window.__inj=1" data-x="`；
  2. 回车生成，关闭结果弹窗；
  3. 打开「最近」，将鼠标移入该条记录标题。
- **预期**：需求文本作为纯文本渲染，不产生新的 DOM 属性或事件。
- **实际**：`esc()` 仅转义 `& < >`，未转义引号；`aria-label="打开记录：…"` 被提前闭合，生成如下元素：
  `aria-label="打开记录：带引号的需求 " onmouseover="window.__inj=1" data-x=""`；
  鼠标移入即执行脚本，实测 `window.__inj === "1"`。截图 `29-history-attr.png`。
- **影响**：可注入任意同源脚本事件属性。本应用将 API Key 明文存放于 localStorage，同源脚本可直接读取；若需求文本来自剪贴板、共享设备或他人提供的素材，存在凭据被读取的路径。
- **建议**：① `esc()` 同时转义 `"` 与 `'`；② 历史列表改用 `document.createElement` + `textContent` + `setAttribute` 构建，禁止字符串拼接属性；③ 全局排查同类拼接（`data-*`、`aria-label`、`title` 共 7 处）。

#### BUG-02｜S3 / P2 / 安全｜API Key 明文存储且无清除入口

- **复现步骤**：添加 DeepSeek 模型并填入 Key → 读取 `localStorage["pw-custom-models"]`。
- **预期**：密钥不以可读明文长期驻留，且用户可一键清除。
- **实际**：`apiKey` 明文保存（实测长度 35，前缀 `sk-`）；界面仅有一行提示"公用电脑请测试后清除"，无对应操作入口；删除模型可间接清除单条，无"清除全部"。
- **建议**：改用 `sessionStorage`（会话级）或 WebCrypto 加密后再存；增加"清除全部密钥"按钮；输入框保持 `type=password`（现状已满足）。

#### BUG-03｜S3 / P3 / 安全｜缺失 CSP

- **实测**：文档中 `Content-Security-Policy` 出现次数为 0，无 `<meta http-equiv>`。
- **影响**：单文件应用一旦出现 BUG-01 类注入，没有任何兜底限制。
- **建议**：加入 `default-src 'self'; connect-src 'self' https://api.deepseek.com …; img-src data:; style-src 'unsafe-inline'; script-src 'unsafe-inline'`（内联脚本与样式需要，可按实际逐步收紧）。

#### BUG-04｜S3 / P2 / 功能｜推理模型输出预算固定导致截断与审阅失败

- **复现步骤**：选择真实 `deepseek-flash`，详细程度"标准"，开启深度模式，输入"写一份给新人的代码评审清单提示词"后发射。
- **预期**：初稿完整，深度模式第二轮返回修订稿。
- **实际**（实测 41.3s）：
  - 初稿 788 字即 `finish_reason: length`，结果页提示"模型输出提前中断（触达输出上限（length）），已保留收到的 788 字"；
  - 第二轮审阅返回仅含 `reasoning_content`，界面提示"深度审阅第二轮失败（模型只返回了推理内容…），已保留初稿"；
  - 另一用例中 `deepseek-v4-pro` 在 4096 预算内同样只返回推理内容（对比结果 1/2 成功）。
- **根因**：`budgetForProfile()` 对推理模型恒返回 `4096`，不读取模型 `max_output_tokens`，且用户不可调。
- **建议**：① 预算改为可配置（设置面板增设"输出预算"）；② 对 `/models` 返回的 `max_output_tokens` 取上限做安全裁剪；③ 截断时自动发起"续写"请求而非直接交付；④ 对 reasoning 与正文分别计量。

#### BUG-05｜S3 / P2 / 交互｜沟通弹窗关闭语义错误

- **复现步骤**：流程设为"先沟通再生成" → 发射 → 第 1 轮出现 → 点击右上角 `✕`（`aria-label="关闭"`）。
- **预期**：关闭弹窗并退出沟通流程（或明确提示"退出将不保存回答"）。
- **实际**：弹窗不关闭，标题由"沟通补充 · 第 1 轮"变为"第 2 轮"，输入区保持隐藏（`composer.gone`）。Esc 与点击遮罩同样表现（截图 `13-close-during-ask.png`）。
- **影响**：用户无法用常规"关闭"语义退出，只能逐轮跳过或使用"跳过剩余 N 轮"。
- **建议**：将"关闭"改为"退出沟通并回到待机"，"跳过本轮"保留独立按钮；或在 `✕` 上改用"退出沟通"文案与 `aria-label`。

#### BUG-06｜S3 / P2 / 功能｜代理 5xx 后真实错误丢失

- **复现步骤**：上游返回 500（响应体 `{"error":{"message":"mock upstream exploded"}}`），页面经 `/api/proxy` 发起请求。
- **预期**：结果页显示上游真实原因（或代理 + 直连两段诊断）。
- **实际**：结果页警示为"not found 已自动改用离线规则出稿，内容仍可直接使用"——代理的 500 与上游错误体被丢弃，仅保留直连 404 的文本（`readApiError` 读取的是直连响应）。
- **建议**：`proxyError` 保存代理侧状态码与响应体摘要，直连失败时按"代理：… / 直连：…"两段输出，与 1.5.1 已实现的 `TypeError` 双段诊断保持一致。

#### BUG-07｜S3 / P2 / 界面｜缺 Key 模型仍标记为"模型生成"

- **复现步骤**：添加模型时 Key 留空 → 保存（成功）→ 观察顶栏状态胶囊与底部标签。
- **预期**：缺 Key 的模型不应被选为生成模型，或状态明确标注"缺 API Key"。
- **实际**：状态胶囊显示"模型生成"，标签显示"生成模型 · DeepSeek 测试"；随后"测试连接"报"该模型没有保存 API Key"，发射后必然失败并回退离线。列表内该模型同时不计入 `usableProfiles()`，与状态栏表述不一致（截图 `15-result-fallback.png`）。
- **建议**：保存时对非本地地址强制校验 Key；或在 `updateModeStatus()` 中按 `usableProfiles()` 判定并显示"缺 Key / 不可用"。

#### BUG-08｜S3 / P3 / 界面｜分组标题被其它选项覆盖

- **复现步骤**：打开「功能」→ 详细程度选"标准"（标题右侧显示"标准"）→ 响应超时选"30s"。
- **预期**：标题继续显示详细程度当前值。
- **实际**：标题变为"生成设置 30"，详细程度当前值在标题上不可见（截图 `12-panel-title-mismatch.png`）。首次进入面板时标题显示"生成设置 详尽"但超时值 120s 不可见，同理。
- **根因**：L2899-2901 用 `closest(".menuGroup").querySelector(".menuTitle b")` 回写，同一分组内两个 `.seg` 都命中第一个标题节点。
- **建议**：按 `seg.parentNode.dataset.seg` 绑定独立标题节点（或改为"详细程度 · 标准 / 超时 · 120s"两个独立小标题）。

#### BUG-09｜S3 / P3 / 文案｜对比模型数提示不一致

- **复现步骤**：本地存有 12 个可用模型，点击"多模型对比"。
- **实测**：toast 显示"会用 12 个模型各生成一版"；顶栏标签显示"多模型对比 · 4 个模型参与"；实际请求 4 个。
- **根因**：L2925-2927 使用 `usableProfiles().length`，未做 `slice(0,4)`/`min(4,n)` 处理（`refreshCaps()` 已处理）。
- **建议**：与 `refreshCaps()` 复用同一计算函数。

#### BUG-10｜S4 / P3 / 功能｜对比模式不持久

- **实测**：切换"多模型对比"后刷新，模式回到"单模型"，其余设置（详细程度 / 超时 / 深度 / 模块 / 模型选择）均保留。
- **建议**：把 `mode` 写入 `pw-settings`。

#### BUG-11｜S4 / P3 / 文案｜回退提示重复、缺标点

- **实测文本**：
  - `模型只返回了 4 个字符，内容不完整，已改用离线规则。 已自动改用离线规则出稿，内容仍可直接使用。`
  - `已取消等待 已自动改用离线规则出稿，内容仍可直接使用。`
- **建议**：回退场景统一为"原因（一句）＋处置（一句）"，避免两处同时拼接。

#### BUG-12｜S4 / P3 / 文案｜回退 / 取消仍显示耗时徽标

- **实测**：回退结果页显示"共 0.0s · 流式"；取消后显示"共 0.7s · 流式"，该数值来自被中止的请求，非生成本次内容的耗时。
- **建议**：`mode === "fallback"` 时不渲染 `.resSpeed`。

#### BUG-13｜S4 / P3 / 界面｜单版本成功信息不完整

- **实测**（2 个模型对比，1 个失败）：结果页 `meta` 为"模型 · 1/2 个模型成功"，无版本标签，界面未标注成功版本来自哪个模型；同时警示语"已保留收到的 379 字"取自第 0 版长度，而被截断的版本为 300 字。
- **建议**：成功版本标题直接使用模型名；截断文案取 `variant.meta.chars`。

#### BUG-14｜S4 / P3 / 界面｜首字耗时 0.0s

- **实测**：`首字 0.0s · 共 0.2s · 流式`（真实首字约 20-50ms）。
- **建议**：小于 0.1s 显示"<0.1s"。

#### BUG-15｜S4 / P3 / 交互｜空"模型 ID"被静默替换

- **复现步骤**：添加模型 → 选择服务商模板 DeepSeek → 清空"模型 ID" → 点击保存。
- **预期**：按必填校验拦截（与"请填写模型 ID"提示一致）。
- **实际**：保存成功，`modelId` 被静默填为模板默认 `deepseek-flash`，无任何提示。
- **建议**：二选一——保留兜底则在输入框下方注明"留空使用模板默认值"，或改为直接报错。

#### BUG-16｜S4 / P3 / 可维护性｜界面无版本号

- **实测**：全文件检索无应用自身版本字符串（`1.5.1` 出现 0 次），界面无版本展示位。
- **影响**：开发文档多次要求"强刷、避免旧标签"，但用户与测试无法在界面上核对实际运行版本。
- **建议**：顶栏品牌区或"功能"面板底部显示 `v1.5.1`，并输出到 `console` 一次。

## 5. 改进建议（按优先级）

### P1（安全，先修）

1. **统一转义策略**：`esc()` 增加 `"` `'` 转义；所有 `data-*` / `aria-*` / `title` 属性改用 `setAttribute`；历史、结果、模型列表三处字符串拼接统一改造（BUG-01）。
2. **密钥管理**：默认写入 `sessionStorage`，或 WebCrypto 加密后再落盘；提供"清除全部密钥"入口；页面关闭时可选清除（BUG-02）。
3. **增加 CSP**：至少 `default-src 'self'` + 白名单 `connect-src`，配合禁用 `eval`（BUG-03）。

### P2（功能与可诊断性）

4. **输出预算可配置**：设置面板增加"输出上限"，读取模型 `max_output_tokens` 作为上限，截断时自动续写（BUG-04）。
5. **关闭语义分层**：`✕`/Esc/遮罩 = 退出沟通；"跳过本轮""跳过剩余 N 轮"保留在原位；退出时给出一次确认（BUG-05）。
6. **错误诊断合并**：代理与直连两侧错误同时保留并分段展示；`readApiError` 的 360 字截断对 HTML 错误页保留状态码（BUG-06）。
7. **模型可用性前置校验**：缺 Key 时禁止选中或显式标注"不可用"，并与 `usableProfiles()` 保持一致（BUG-07）。

### P3（一致性与文案）

8. 设置面板标题按 `data-seg` 绑定，避免互相覆盖（BUG-08）。
9. 对比数量统一由 `min(4, usableProfiles().length)` 计算，toast / 标签 / 实际请求三处同源（BUG-09）。
10. `mode` 纳入持久化（BUG-10）；回退文案去重并统一标点（BUG-11）；回退/取消不显示耗时徽标（BUG-12）；单版本成功标注模型名、截断字数取对应版本（BUG-13）；首字 <0.1s 显示 `<0.1s`（BUG-14）。
11. 空"模型 ID"行为与必填提示保持一致（BUG-15）；界面增加版本号并在控制台输出一次（BUG-16）。

### 性能与工程

12. **待机动画降载**：待机 3–5s 后把粒子数量降到 1/3 或暂停重绘；`document.hidden` 时停止 `rAF`；生成期间暂停背景 canvas，只保留轨道动画。当前粒子数 9,000、圆盘 25，待机主线程占用约 25%（136fps 环境）。
13. **可测性**：`?debug=1` 暴露的 `__pwDebug` 建议在正式版保留但改名隐藏；为请求层补充 `?mock=` 入口便于回归（本次测试即通过此思路完成 14 类异常验证）。
14. **体积**：单文件 498KB（含 base64 字体约 300KB+）。内网/离线分发可接受；若走 HTTP，建议开启 gzip/brotli 并评估字体子集是否可再裁剪。
