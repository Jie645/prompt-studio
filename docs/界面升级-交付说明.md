## 1. 设计说明

选了主推方向 **深空玻璃 · 能量流**：底子是带靛青倾向的深空蓝黑（不是中性黑，也不是纯黑），
面板用「半透明玻璃 + 1px 发丝边 + 内高光 + 柔和外阴影」分层，而不是靠粗分割线；
强调色收成**一条青→紫的渐变**（`#4dd8e8 → #8b7cff`），只出现在主按钮、激活标签指示条、
流水线推进光带、聚焦环、生成中的边框流光这五处 —— 稀缺才显高级。
圆角统一三档（10/14/20），所有颜色、阴影、间距、缓动、层级收敛进 `:root`。
动效策略：**短动效 120–320ms 表达"发生了什么"，长周期 1.5–60s 只做背景与状态呼吸**，
同一时刻屏幕上最多 3 处运动（流水线 + 编辑器边框 + 计量数字），且全部在 `prefers-reduced-motion` 下停到最终态。

## 6. 未做与风险

1. **`#scoreChip` 的"从 0 计数到目标值"没做**：该数字由 JS 直接写进 `textContent`，纯 CSS 无法读取它做 `counter` 动画；
   按文档给的备选方案退化成「出现时一次 pop + 档位换色过渡」。硬做需要 `@property` + `counter` + JS 暴露数值，代价高于收益。
2. **`.editor-shell::before` 的边框流光依赖 `@property`**（Chromium 111+/Edge 支持）。不支持时动画不跑，
   但那条边框渐进色仍以静态形式存在；`prefers-reduced-motion` 下就是静态亮边。
3. **`background-position` 用在了流水线光带上**：文档把它列为该动效的许可实现（"用 background-position 或 transform"）。
   它只触发绘制、不触发重排，且元素高度仅 1px，开销可忽略。
4. **`.tabs::after` 的指示条按固定标签宽度（68px + 2px gap）计算位移**，所以给 `.tab` 设了 `min-width: 68px`；
   窄屏（≤900px）标签换行时该指示条直接隐藏，避免错位。
5. **`.critique-out` 的样式保留了**（选择器不在文档点名的死样式清单里，且与 `.analysis-out` 同一组），
   其余四项死样式（`.score-bar` / `.round-row` / `.round-score` / `.total-num` / `#tempOut`）已删除 ——
   删之前已核对 `public/js/**` 中零引用。
6. **窄屏 375px 下侧栏排在最上方**，提示词区在折叠下方（单列布局的必然结果）；若希望窄屏先看结果，
   需要调整 `index.html` 的 DOM 顺序 —— 那属于结构改动，本轮不做。
