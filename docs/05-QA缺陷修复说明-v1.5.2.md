## 2. 关键实现要点

1. **密钥分层**（新增约 85 行）
   - 存储键：`pw-model-secrets`（持久，仅 `remember:true`）、`pw-model-secrets-s`（会话）。
   - `loadCustomModels()` 读到旧版明文 `apiKey` 时搬入密钥库并按「已记住」处理（避免升级后掉密钥），随后立刻把 `pw-custom-models` 重写成不含密钥的形态；`saveCustomModels()` 只写 `hasKey` 布尔。不想保留就点「清除全部密钥」。
   - `usableProfiles()` / `updateModeStatus()` 统一走 `profileReady()`，避免状态与真实可用性分叉。
2. **预算分层**：`SET.budget`（用户选择）→ `budgetForProfile()`（推理模型下限 8192）→ `modelBody()`（硬上限 16384）。截断仍保留「重试模型」入口。
3. **深度审阅兜底**：第二轮失败且错误属于「只返回推理内容 / 没有返回文本 / 触达输出上限」时，用一条「只输出修订稿全文」的极简指令重试一次，仍失败才回落到初稿。
4. **esc 统一**：属性与文本共用一套转义（含引号），历史/模型/结果三处列表无需再单独处理。

## 4. 已知限制（未在本版处理）

1. **明文传输面**：密钥仍以明文存在于内存与（勾选记住时的）localStorage；未做 WebCrypto 加密（无硬件可信根，纯前端加密对同源脚本不构成防护）。
2. **自动续写**：截断时仍提示「重试模型」，未实现自动续写第二次请求（消耗翻倍，留待产品决策）。
3. **CSP 粒度**：`script-src` 必须保留 `'unsafe-inline'`（单文件内联）；`connect-src` 需要放开 `http:`/`https:` 以支持任意自建接口，因此主要价值在阻断远程脚本与 `data:` 脚本。
4. **旧版对比**：1.5.1 保留在目录内，可用 `http://127.0.0.1:8787/?v=1.5.1` 对照复现原缺陷。
