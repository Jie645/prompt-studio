# Prompt Studio · 单文件修订版

这是 `轨道算术 · 提示词工作台` 的单文件版本，已按 2026-10-17 的 10 项问题复核完成整改，并加入简化的模型接入。

## 直接打开

直接双击 `index.html` 可使用离线规则；要调用云端模型，双击 `run.cmd` 启动本地代理，再使用浏览器打开的 `http://127.0.0.1:8787/`。

也可以打开 `预览.html` 查看整改后的桌面和 320px 移动端预览。

## 本次修复

- 深度模式在模型模式下执行真实的“初稿 → 审稿 → 修订”两轮请求；第二轮失败保留初稿并提示。
- 生成 Prompt 只保留一次需求原文，删除“不要复述需求”与“先复述目标”的冲突。
- 320px 下功能面板避开固定导航，底部按钮换行，页面无横向溢出。
- 分段控件补齐 `aria-pressed`；删除二次确认同步更新 `aria-label`。
- 多模型底部显示参与数量；失败文案区分全部失败与部分失败。
- 空模型表单、第 1 轮空提交、模型调用失败均有可见反馈。
- 模型接入支持 OpenAI / DeepSeek / 阿里云百炼 / Kimi / 智谱 / Anthropic / Ollama 服务商模板。
- 选择模板后自动填入接口地址、推荐模型和协议；模型弹窗内可直接测试连接。
- 支持 OpenAI Chat Completions、Responses API 与 Anthropic Messages；接口地址自动规范化。
- `run.cmd` 启动本地代理，绕过浏览器对云端接口的 CORS 限制。

详细说明见 [修改说明书.md](修改说明书.md)。
